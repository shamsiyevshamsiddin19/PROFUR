# UX/UI — Draft Screen Inventory

## Admin Web
- Dashboard: multiple active projects and stages
- Material catalog and warehouse movements
- Create project/order and add model variants
- Planned material/cost calculator
- Worker/task progress and discrepancy alerts
- Packaging and delivery
- History and final statistics
- Users/roles/permissions (USER-PROPOSED, pending approval)

## Worker Mobile
- Login / identify worker
- Assigned tasks
- Task details, accept task
- Record parts worked and actual material usage
- Explain over-norm use or discrepancies
- Task history

## Design prerequisites
Permission matrix and group accounts, Android/iOS target, language, offline support and partial workflows need clarification. Wireframes can start as assumptions-labeled drafts.
